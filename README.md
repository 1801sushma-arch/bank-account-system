# bank-account-system (Python OOP)

## 📌 Description
A simple Python project that simulates basic bank account operations using Object-Oriented Programming (OOP).

## 🚀 Features
- Create a bank account
- Deposit money
- Withdraw money
- Check account balance

## 🧠 Concepts Used
- Classes & Objects
- Constructors (__init__)
- Methods
- Encapsulation (basic)

## ▶️ How to Run
1. Make sure Python is installed
2. Run the file:
   python bank-account-system.py

## 💡 What I Learned
- How to structure code using classes
- Difference between functions and methods
- Managing state using objects
- Writing cleaner and reusable code
